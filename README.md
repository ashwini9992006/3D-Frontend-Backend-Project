
# FlowStack - 3D Frontend and Backend Visualization

An interactive project that demonstrates how a frontend communicates with a backend using HTTP requests and JSON responses.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Features

- 3D-style frontend, backend and database visualization
- Animated communication flow
- Real HTTP request to the Express backend
- JSON response display
- Activity log

## Installation

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:

   npm install

5. Start the server:

   npm start

6. Open your browser:

   http://localhost:3000

## API Endpoints

- GET /api/health - Checks backend status.
- POST /api/demo - Returns sample JSON data.

## Note

The database layer is simulated using sample data. No real database is connected.
